Drive Only Notes는 옵시디언 안에서 드라이브의 Markdown·텍스트 노트를 읽고 쓰는 도구입니다. 기기에는 아직 전송하지 못한 수정 내용만 임시저장합니다.

데이터 처리 방식 보기사용 범위 확인

두 기기에서 같은 노트

Windows PC와 Android 폰이 사용자가 지정한 같은 드라이브 폴더에 연결됩니다. Android에서는 별도의 연결 도우미가 Google 인증을 담당합니다.

전송 전까지 임시 보관

수정 내용을 기기에 먼저 기록하고 드라이브에 전송합니다. 원격 내용을 다시 읽어 저장을 확인한 뒤 해당 임시 사본을 지웁니다.

충돌하면 사본으로

다른 기기에서 먼저 수정된 노트는 자동으로 덮어쓰지 않습니다. 미전송 내용을 보관하고 사용자가 별도 사본으로 저장할 수 있습니다.

Google 연결이 필요한 이유

노트와 폴더를 사용자의 Google Drive에서 읽고 만들고 수정하기 위해 Google의 drive.file 권한을 사용합니다. 앱이 만든 드라이브 자료에 접근하며, Google 비밀번호를 직접 받지 않습니다.

PC·폰과 Google 사이에서 직접 통신합니다. 노트 본문을 받는 개발자 운영 중계 서버나 광고·분석 시스템은 없습니다. 원격 파일에는 사용자가 지정한 Google Drive 폴더의 공유 설정이 적용됩니다.

개인정보처리방침에서 접근 정보, 임시저장, 연결 해제 및 데이터 삭제 방법을 확인할 수 있습니다.

지원 범위

  • 옵시디언 내부의 전용 텍스트 편집 화면
  • 5MB 이하의 Markdown(.md)·텍스트(.txt) 노트
  • 폴더·노트 생성, 제목 검색, 자동 저장, 임시저장 복구, 충돌 사본

기본 그래프·백링크·첨부파일·Canvas·Google Docs 편집·원격 삭제는 현재 버전에 포함하지 않습니다. 이 개인용 프로젝트는 Google 또는 Obsidian의 공식 제품이 아닙니다.
