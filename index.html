Drive Only Notes는 옵시디언 안에서 드라이브의 Markdown·텍스트 노트를 읽고 쓰는 도구입니다. 기기에는 아직 전송하지 못한 수정 내용만 임시저장합니다.

데이터 처리 방식 보기사용 범위 확인

두 기기에서 같은 노트

Windows PC와 Android 폰이 사용자가 지정한 같은 드라이브 폴더에 연결됩니다. Android에서는 별도의 연결 도우미가 Google 인증을 담당합니다.

전송 전까지 임시 보관

수정 내용을 기기에 먼저 기록하고 드라이브에 전송합니다. 원격 내용을 다시 읽어 저장을 확인한 뒤 해당 임시 사본을 지웁니다.

충돌하면 사본으로

다른 기기에서 먼저 수정된 노트는 자동으로 덮어쓰지 않습니다. 미전송 내용을 보관하고 사용자가 별도 사본으로 저장할 수 있습니다.

Google 연결이 필요한 이유

노트와 폴더를 사용자의 Google Drive에서 읽고 만들고 수정하기 위해 Google의 drive.file 권한을 사용합니다. 앱이 만든 드라이브 자료에 접근하며, Google 비밀번호를 직접 받지 않습니다.

PC·폰과 Google 사이에서 직접 통신합니다. 노트 본문을 받는 개발자 운영 중계 서버나 광고·분석 시스템은 없습니다. 원격 파일에는 사용자가 지정한 Google Drive 폴더의 공유 설정이 적용됩니다.

개인정보처리방침에서 접근 정보, 임시저장, 연결 해제 및 데이터 삭제 방법을 확인할 수 있습니다.

지원 범위 · 플러그인 0.4.0

  • 옵시디언 기본 새 노트·Ctrl+N·기본 편집기·파일 탐색기로 Drive 노트 사용
  • 5MB 이하 Markdown(.md)·텍스트(.txt), Canvas·Bases 텍스트 저장 경로 연결
  • 기본 제목 변경·파일 이동·폴더 생성·자동 저장·암호화 임시저장 복구·충돌 사본
  • 기본 파일 메뉴의 삭제에서 대상 확인 후 Google Drive 휴지통으로 이동

빈 전용 보관함에서 플러그인과 Drive 연결이 켜져 있을 때 기본 새 노트도 Drive에 저장합니다. 연결 전 쓰기는 로컬 원본으로 우회하지 않습니다. 파일 복구와 Obsidian Sync는 끄고 사용하며 링크·속성 색인은 실행 중 메모리에 둡니다. 첨부 이미지·PDF·오디오, Google Docs, 폴더 삭제·영구 삭제는 지원하지 않습니다. 목록 2,000개·폴더 깊이 12단계까지이며 모든 Canvas·Bases 기능과 타사 플러그인 호환성을 보장하는 버전은 아닙니다. Obsidian 1.14.4에서 기본 편집·양방향 저장·임시저장 복구·휴지통을 검사했으며 Obsidian 업데이트 후에는 재검증이 필요합니다.

플러그인은 배포된 세 파일을 교체해 업데이트합니다. 도우미 0.4.1부터는 앱의 ‘업데이트 확인’에서 서명된 버전 정보를 확인하고 APK를 내려받아 Android 설치 화면으로 연결합니다. 최종 설치는 사용자가 직접 확인합니다. 이 개인용 프로젝트는 Google 또는 Obsidian의 공식 제품이 아닙니다.
