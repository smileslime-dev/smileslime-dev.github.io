개인정보처리방침

이 문서는 Drive Only Notes 플러그인과 Android용 Drive Only 연결 도우미가 Google 사용자 데이터와 기기 데이터를 어떻게 처리하는지 설명합니다.

1. 운영 주체와 적용 범위

Drive Only Notes는 프로젝트 소유자의 Windows PC와 Android 기기에서 사용하는 개인용 노트 도구입니다. 문의 및 데이터 처리 관련 연락처는 smileslime.dev@gmail.com입니다. 이 안내 웹사이트의 운영 주체도 동일합니다.

2. 접근하는 Google 데이터와 목적

앱은 https://www.googleapis.com/auth/drive.file 권한을 요청합니다. 이 앱이 만든 드라이브 폴더·노트의 이름, 파일 ID, 폴더 관계, 파일 종류·크기, 버전 정보와 노트 본문을 읽고, 사용자의 편집에 따라 폴더·노트를 만들거나 수정합니다. 이러한 정보는 노트 목록 표시, 읽기·저장, 충돌 확인 및 저장 결과 검증에 사용됩니다.

이 권한의 Google 안내 문구에는 삭제가 포함될 수 있으나 현재 앱에는 원격 파일 삭제 기능이 없습니다. 앱은 드라이브 전체 접근 권한, Gmail·연락처 권한을 요청하지 않으며 Google 비밀번호를 직접 입력받지 않습니다.

3. 저장 위치와 보관 기간

  • 노트 원본: 사용자가 연결한 Google Drive 폴더에 보관합니다. 사용자가 Drive에서 삭제할 때까지 유지되며 Drive의 저장·휴지통 정책이 적용됩니다.
  • 열어 본 본문: 앱 실행 중 메모리에 둡니다. 정상적으로 저장된 노트의 전용 영구 본문 캐시나 일반 보관함 노트 파일을 만들지 않습니다.
  • 미전송 수정 내용: 0.3.0부터 플러그인의 temporary-drafts 폴더에 AES-256-GCM 암호문으로 임시저장합니다. 제목과 본문을 함께 암호화하며, 키는 Windows에서 현재 사용자 DPAPI로 보호하고 Android에서는 옵시디언 SecretStorage에 보관합니다. 키나 기기 데이터를 잃으면 미전송 내용을 복구하지 못할 수 있습니다. 이전 버전의 평문 임시저장은 암호화 사본의 기록과 복호화를 확인한 뒤 이전합니다. 원격 본문·제목·폴더를 다시 확인해 저장이 검증되면 해당 임시 사본을 삭제합니다. 전송 실패·충돌 시에는 기간만으로 삭제하지 않으며 사용자가 복구하거나 명시적으로 버릴 때까지 보존합니다.
  • Windows 로그인: 갱신 토큰을 Windows 현재 사용자 계정의 DPAPI로 암호화해 보관하고 접근 토큰은 메모리에 둡니다. OAuth 앱 설정과 드라이브 폴더 정보도 해당 기기의 플러그인 설정에 보관합니다.
  • Android 로그인: Google Play Services가 계정 승인 상태를 관리합니다. 연결 도우미와 플러그인은 접근 토큰을 파일로 영구 저장하지 않습니다. 연결 도우미의 기기 연결 키는 앱 전용 저장소에, 플러그인 쪽 연결 키는 옵시디언 SecretStorage에 보관합니다.

설정 폴더를 다른 동기화·백업 서비스에 연결하면 설정이나 미전송 임시저장이 그 서비스에 복제될 수 있습니다. 일반 파일 삭제는 운영체제 백업·스왑이나 저장 장치의 복구 불가능한 삭제를 보장하지 않습니다.

4. 전송과 제3자 제공

앱은 사용자의 기기에서 Google 인증 서비스와 Google Drive API로 직접 통신합니다. Android 연결 도우미는 같은 폰의 로컬 주소에서 서명된 요청·복귀 주소·응답과 일회성 비밀값을 확인하고 접근 토큰을 플러그인에 전달합니다.

개발자가 운영하는 서버로 노트 본문을 수집하거나 보관하지 않습니다. Google 사용자 데이터를 판매하거나 광고, 사용자 프로파일링, AI 모델 학습에 사용하지 않습니다. 별도의 분석·광고 추적 코드를 포함하지 않습니다. 사용자가 지정한 Drive 폴더의 공유 설정은 Google Drive에서 관리합니다.

Google과 Obsidian 등 외부 제품 자체의 데이터 처리는 각 제공자의 정책을 따릅니다. Google 개인정보처리방침과 Obsidian 개인정보처리방침을 참고할 수 있습니다. 다른 옵시디언 플러그인은 사용자가 설치한 범위와 권한에 따라 기기 설정이나 임시저장에 접근할 수 있습니다.

5. 연결 해제와 데이터 삭제

플러그인의 ‘이 기기 연결 해제’는 그 기기의 Google 연결을 비활성화하며, 드라이브 노트와 미전송 임시저장은 유지합니다. Google 계정의 연결 관리에서 앱 접근을 취소할 수 있습니다. 취소 후 다시 연결하려면 Google에서 다시 동의해야 할 수 있습니다.

미전송 본문은 앱의 ‘기기 임시저장’ 목록에서 확인하고 명시적으로 버릴 수 있습니다. 드라이브의 원본은 사용자가 Google Drive에서 직접 삭제할 수 있습니다. 플러그인이나 도우미의 기기 데이터 삭제·제거 시 해당 기기의 설정과 복구하지 않은 임시저장을 잃을 수 있습니다.

6. 이 안내 웹사이트

안내 페이지에는 로그인·노트 업로드 기능, 광고, 자체 분석 스크립트가 없습니다. GitHub Pages로 공개하는 경우 GitHub는 보안 목적으로 방문자의 IP 주소를 기록할 수 있습니다. 해당 호스팅 처리에는 GitHub 개인정보처리방침이 적용됩니다.

7. 변경 및 문의

앱의 데이터 처리 방식이 바뀌면 이 문서와 앱 내 안내를 갱신합니다. Google 데이터의 용도나 권한이 달라지는 경우에는 새로운 처리에 앞서 필요한 동의를 요청합니다.
