시행일 2026년 10월 19일 · 버전 0.6.3

개인정보처리방침

Obsidian Drive Bridge 플러그인과 Android 앱의 Google 데이터 및 기기 데이터 처리 방식을 설명합니다. 0.5.0부터 노트와 첨부파일을 기기에도 저장합니다.

1. 운영 주체와 문의

Obsidian Drive Bridge는 Windows PC와 Android에서 사용하는 개인용 노트 동기화 프로젝트입니다. 안내 사이트와 앱 관련 문의는 smileslime.dev@gmail.com으로 받습니다.

2. Google 데이터 접근 목적

https://www.googleapis.com/auth/drive 권한으로 사용자가 연결한 Drive 폴더와 그 하위 파일의 이름·ID·폴더 관계·종류·크기·버전 정보·내용을 처리합니다. 사용자가 연결한 보관함의 파일을 내려받고 만들고 수정하고 이동하며, 기기에서 삭제한 자료는 Drive 휴지통으로 이동합니다. 폴더는 자식 파일 처리와 비어 있는 상태를 확인한 뒤 휴지통으로 보냅니다. 영구 삭제·휴지통 비우기는 제공하지 않습니다.

이 정보는 기기 간 동기화, 충돌 확인, 전송 결과 검증과 복구에 사용됩니다. Google이 허용하는 접근 범위는 전체 Drive입니다. 앱은 사용자가 연결한 폴더와 하위 폴더만 동기화하며 기존 사용자는 새 권한에 다시 동의해야 합니다. Gmail·연락처 권한은 요청하지 않으며 Google 비밀번호를 직접 입력받지 않습니다.

3. 기기와 Drive의 저장 위치

  • 노트와 첨부파일: 일반 옵시디언 보관함의 실제 파일로 PC·폰에 저장하고 지정한 Google Drive 폴더에도 저장합니다. 이 플러그인이 로컬 노트 자체를 암호화하지는 않습니다. 옵시디언의 기본 색인·작업공간·파일 복구도 사용할 수 있습니다.
  • 동기화 기록: 파일 ID·경로·버전·내용 해시·전송 예약·이동 정보 등을 각 기기의 플러그인 폴더에 보관합니다. Google 인증정보는 동기화하지 않습니다.
  • 복구 사본과 휴지통: Drive에서 받은 내용으로 기존 파일을 교체하기 전에 이전 기기 내용을 파일별 최대 5개씩 보관합니다. 사용자가 별도 파일로 복원할 수 있습니다. Drive 삭제를 반영한 로컬 파일은 옵시디언 로컬 휴지통으로 옮깁니다. 복구 사본과 휴지통은 사용자가 기기에서 관리합니다.
  • 충돌: 양쪽에서 다르게 수정된 파일은 일반 로컬 충돌 사본으로 보존하고 Drive에도 동기화합니다.
  • 이전 암호화 임시저장: 0.4.0 이전의 AES-256-GCM 임시저장은 해당 기기에서 복호화해 일반 파일로 복구합니다. 원래 암호화 사본도 자동으로 지우지 않습니다. 읽을 수 없는 기록은 보존하고 이전을 중지합니다.
  • Windows 로그인: 갱신 토큰을 현재 Windows 사용자 DPAPI로 보호하고 접근 토큰은 메모리에 둡니다. OAuth 앱 설정과 연결 폴더 정보는 해당 기기의 설정에 보관합니다.
  • Android 로그인: Google Play Services가 계정 승인 상태를 관리합니다. 접근 토큰은 파일로 영구 저장하지 않습니다. 앱의 연결 키는 앱 전용 저장소에, 플러그인 연결 키는 옵시디언 SecretStorage에 보관합니다.

노트·첨부파일은 사용자가 삭제할 때까지 각 저장 위치에 남습니다. 기기 백업·다른 플러그인·운영체제 스왑에는 별도 사본이 남을 수 있습니다. 설정 폴더와 인증정보를 다른 기기에 복사하지 마세요.

플러그인 설치 기능

PC 설치 프로그램과 Android 앱은 사용자가 선택한 보관함 또는 새 보관함을 둘 위치에 필요한 폴더와 플러그인 파일 세 개를 설치합니다. 설치 기능은 노트 본문·Google 로그인 설정·동기화 기록을 읽거나 변경하지 않습니다. Windows에서는 기존 보관함의 이름과 경로를 목록에 표시할 수 있습니다. Android는 시스템 폴더 선택 화면으로 접근을 허용받습니다. 기본 보관함은 Documents/Obsidian Drive Bridge에 준비하며, 사용자가 허용한 폴더 접근을 다음 업데이트를 위해 기억합니다. 앱의 ‘폴더 접근 권한 해제’로 해제할 수 있습니다. 기존 보관함을 직접 선택하는 설치는 접근을 영구 보관하지 않습니다. 기기 전체 파일 접근 권한은 요청하지 않습니다. 이전 프로그램 파일은 PC 사용자 앱 데이터 또는 Android 앱 전용 저장소에 백업합니다. Obsidian의 플러그인 신뢰 확인은 사용자가 직접 진행합니다.

4. 통신과 제3자 제공

앱은 기기에서 Google 인증 서비스 및 Drive API로 직접 통신합니다. Android 앱은 같은 폰의 로컬 주소로 서명된 요청·복귀·응답을 확인해 접근 토큰을 전달합니다. 개발자 운영 서버로 노트 본문을 수집하지 않으며 판매·광고·프로파일링·AI 학습에 사용하지 않습니다. 자체 광고·분석 추적 코드는 없습니다. Drive 폴더의 공유 설정은 Google에서 관리합니다.

앱을 열면 6시간 간격으로, 또는 사용자가 ‘업데이트 확인’을 누르면 GitHub Pages의 전용 HTTPS 주소에서 서명된 버전 정보를 받습니다. 사용자가 다운로드·설치를 요청하면 APK를 받습니다. 이 요청에 노트·Google 토큰·연결 코드를 넣지 않습니다. 서명·해시·크기·패키지·버전·인증서를 검증한 후 Android 설치 화면을 열며 최종 설치는 사용자가 결정합니다.

외부 서비스에는 Google 개인정보처리방침과 Obsidian 개인정보처리방침이 적용됩니다. 사용자가 설치한 다른 플러그인은 기기 파일과 설정에 접근할 수 있습니다.

5. 연결 해제와 삭제

‘이 기기 연결 해제’는 자동 전송을 멈추고 Google 연결을 비활성화합니다. 기기와 Drive의 파일·동기화 기록·복구 사본은 유지합니다. Google 계정에서 앱 접근을 취소할 수도 있습니다.

동기화 중 일반 파일 삭제는 다른 기기와 Drive에도 반영됩니다. 기기에만 있는 사본을 정리하려면 먼저 그 기기의 동기화를 중지하고 삭제 범위를 확인하세요. 로컬·Drive 휴지통에서 복원할 수 있으며 Drive의 보관 정책이 적용됩니다. 플러그인 제거만으로 일반 보관함 노트가 삭제되지는 않지만, 앱 데이터 삭제나 앱 전용 저장소 제거는 파일·설정·복구 기록을 잃게 할 수 있습니다.

6. 안내 사이트와 변경 안내

이 사이트에는 로그인·노트 업로드·광고·자체 분석 기능이 없습니다. GitHub Pages의 보안 목적 IP 기록 등에는 GitHub 개인정보처리방침이 적용됩니다. 앱의 데이터 처리 방식이 바뀌면 이 문서와 앱 내 설명을 갱신하고 필요한 동의를 받습니다.
