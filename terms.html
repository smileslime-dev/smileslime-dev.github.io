이용약관

Drive Only Notes의 현재 제공 범위와 이용 조건을 안내합니다.

1. 제공 대상과 목적

Drive Only Notes는 프로젝트 소유자가 자신의 Google 계정으로 Windows PC와 Android 기기에서 사용하는 개인용 노트 도구입니다. 별도의 회원 가입, 유료 결제, 구독 또는 개발자 운영 노트 저장 서버를 제공하지 않습니다. 문의 연락처는 smileslime.dev@gmail.com입니다.

2. 사용 환경과 기능 범위

옵시디언의 전용 텍스트 편집 화면에서 Google Drive의 5MB 이하 Markdown·텍스트 노트를 읽고 만들고 수정할 수 있습니다. Android에서는 Drive Only 연결 도우미가 함께 필요합니다. 기본 그래프·백링크·첨부파일·Canvas·Google Docs 편집·원격 삭제는 현재 버전의 기능에 포함하지 않습니다.

사용자는 자신이 접근 권한을 가진 계정과 자료에 연결해야 합니다. Google·Obsidian과의 계정 이용 관계, 저장 용량, 외부 서비스 요금 및 약관은 해당 제공자의 정책을 따릅니다. 이 프로젝트는 Google 또는 Obsidian의 공식 제품이 아닙니다.

3. 저장 상태와 충돌 처리

앱은 편집 내용을 기기에 임시저장한 뒤 드라이브에 전송하며, 실제 원격 내용을 재확인한 후 ‘저장 완료’를 표시합니다. 임시 기록이 완료되기 전의 갑작스러운 종료, 저장 장치 오류, 운영체제 제한 또는 Google 서비스 장애가 발생하면 마지막 입력이 저장되지 않을 수 있습니다.

다른 기기의 수정과 충돌하면 자동 덮어쓰기를 멈추고 미전송 내용을 보존합니다. 사용자는 이를 별도 사본으로 저장하거나, 확인 후 기기의 임시저장을 버릴 수 있습니다. 임시저장 삭제와 앱 데이터 제거는 사용자가 복구할 내용을 먼저 확인한 뒤 진행해야 합니다.

4. 데이터 처리와 이용 중단

Google 데이터와 기기 설정·임시저장의 처리에는 개인정보처리방침이 적용됩니다. 사용자는 플러그인의 연결 해제, Google 계정의 앱 접근 취소 또는 플러그인·도우미 제거를 통해 사용을 중단할 수 있습니다. 드라이브에 보관된 원본은 사용자가 직접 관리합니다.

5. 변경 안내와 문의

제공 범위나 데이터 처리 방식이 바뀌면 이 안내와 필요한 앱 내 설명을 갱신합니다. 이 문서 자체가 외부 서비스의 약관이나 사용자의 법적 권리를 대체하지 않습니다.
